# 「心有灵犀」双人挑战赛

一个用于线下活动的双人猜词挑战赛大屏工具：A 表达者看词用肢体表演，B 猜词者背对屏幕猜词，两分钟内猜对最多的小组获胜。整个应用为单文件 HTML，零依赖、零构建，浏览器直接打开即可使用。

## 玩法规则

- **角色分工**：每组两位搭档，A 负责表演，B 负责猜词，选定后不可交换。
- **挑战流程**：每组一次机会，限时 2 分钟（可配置）。猜对 +1 分并立即切词；PASS 跳过最多 3 次（可配置）；违规作废强制切词。
- **两条禁忌**：绝对不能出声（含谐音、口型），绝对不能指指点点。
- **胜负**：前 3 名获胜；若第 3 名与第 4 名平分，进入「黄金 30 秒生死战」加时赛。

## 功能特性

- **赛制设置**：挑战时长、跳过上限、加时时长均可配置，音效开关。
- **小组管理**：默认 5 组，可增删改名，已完成状态一目了然。
- **词库管理**：8 个内置分类 + 自定义词库，支持 txt / csv 文件导入，随机不重复抽题，抽空自动补充。
- **游戏页**：3-2-1 准备倒计时、环形倒计时（最后 10 秒红色警示）、猜对/跳过/违规三键操作、暂停/继续、随机提示语。
- **成绩单**：猜对/跳过/违规/正确率统计，本轮词表回放（绿=猜对、黄=跳过、红=违规）。
- **龙虎榜**：自动排名，前 3 名冠亚季印章，第 3/4 名平分自动提示加时，支持导出 CSV。
- **加时赛**：双模式——「黄金 30 秒生死战」（两队抢答，平分进入「突然死亡」一词定胜负）与「加时续命挑战」（单队追加时长，得分累加进总分）。
- **键盘快捷键**：主持人单手即可操作全场。
- **音效反馈**：猜对、跳过、违规、最后 10 秒滴答、开场、胜利等音效全部由 Web Audio 实时合成，无需音频文件。
- **数据持久化**：小组与设置自动保存到浏览器 localStorage，刷新不丢失。

## 快速开始

1. 直接用浏览器打开 `index.html`，或部署到任意静态服务器 / GitHub Pages。
2. 在设置页配置参赛小组、赛制与词库，点击「开始比赛」。
3. 大屏投屏给全场，主持人操作键盘，按抽签顺序依次上场。

无任何依赖与构建步骤，纯前端本地运行。

## 键盘快捷键

| 按键 | 场景 | 作用 |
| --- | --- | --- |
| `空格` / `Enter` / `→` | 游戏页 | 猜对 +1 分 |
| `P` | 游戏页 | PASS 跳过 |
| `X` | 游戏页 | 违规作废 |
| `Esc` | 游戏页 | 暂停 / 继续 |
| `←` / `→` | 加时赛·生死战 | A 组 / B 组抢答 |

## 词库与数据

- **内置分类**：中秋团圆、四字成语、飞禽走兽、生活百物、动作场景、影视经典、人间烟火、网络热词。
- **自定义词**：每行一个，或以逗号、空格分隔；支持导入 `.txt` / `.csv`（UTF-8，每行一词）。
- **数据存储**：设置与小组成绩保存在 `localStorage`（键 `xylx_v1`）；换设备或清缓存会导致数据重置，可在设置页「重置全部数据」清空重来。

## 技术概览

- **单文件架构**：HTML / CSS / JS 全部内联于 `index.html`（约 1400 行），无依赖、无构建、无网络请求，开箱即用。
- **计时器**：基于 `requestAnimationFrame` 的驱动循环（`runTimer` / `loop`），支持暂停续跑与中途调整剩余时间；倒计时环为 SVG `stroke-dashoffset` 动画。
- **抽题算法**：选定分类与自定义词合并去重后洗牌成词池（`poolWords` / `shuffle`），按序出题不重复，词池耗尽时自动重新洗牌补充。
- **音效**：Web Audio API 动态创建 Oscillator 合成短音（`tone`），封装为 `SFX` 音效表，无外部音频资源。
- **状态管理**：全局 `state` 对象承载设置、小组、当前轮次（`round`）与加时赛（`ot`），单轮数据与历史词表全程内存记录。
- **视觉场景**：全部 SVG 绘制（月亮、祥云、远山、桂花树、玉兔、灯笼、回纹边框），CSS 动画实现摇曳、漂浮、飘落花瓣；猜对时触发花瓣粒子爆发（`burst`）。
- **界面切换**：6 个 `<section>` 通过 `show()` 互斥显隐，词库设置页可从任意界面进入，返回时自动恢复（游戏中自动暂停、返回续跑）。

## 常见问题

- **词库为空无法开赛**：进入「词库设置」勾选分类或填写自定义词，至少 1 个词。
- **想重新开始**：设置页「重置全部数据」，或清除浏览器该站点的 localStorage。
- **数据在别的设备上看不到**：数据仅存于本地浏览器，换设备需重新配置。
